# Wallet Manager Product Guidelines

## Design Principles
- **Clarity and Precision:** Financial data must be presented clearly with consistent formatting (e.g., currency symbols, date formats).
- **Efficiency:** Minimize the number of taps required to perform frequent actions like recording a transaction or checking a balance.
- **Trust and Security:** Use visual cues (e.g., icons, color coding) to indicate secure states and employee permission levels.

## User Experience (UX)
- **Error Prevention:** Use validation and confirmations for critical actions like balance updates or debt payments.
- **Accessibility:** Ensure high contrast for readability and support for both Arabic and English locales as specified in the README.
- **Consistency:** Maintain a uniform look and feel across all screens using a centralized theme.

## Prose and Communication
- **Tone:** Professional yet approachable, focusing on helpfulness and reliability.
- **Clarity:** Use plain language for technical terms to ensure accessibility for all users, including non-technical store employees.
- **Bilingual Support:** All UI text and messages must be fully localized in both English and Arabic.
